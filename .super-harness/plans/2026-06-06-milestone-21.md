# Milestone 21: 记忆存储 + 写入方式全面改造

**日期:** 2026-06-06
**Spec:** `.super-harness/specs/2026-06-06-memory-system-v3.md`
**依赖:** 无

## 目标

完成记忆系统的所有存储结构和写入方式改造：
- 短期记忆从按 session UUID 改为按日期文件存储
- 长期记忆从按 topic 分文件改为按大分类存储
- 主模型通过 SaveMemoryTool 主动写入偏好/事实/情绪/任务/反思
- Side 在 session 结束时写入事件摘要
- 移除旧的 PrefDetectionTask
- 清理旧数据

## Tasks

- [x] ### Task 1: ShortTermMemory 按日期文件改造 + 内容格式扩展

**文件**: `memory/short_term.py`

改造内容：
- `_session_path()` → `_date_path(date: str)`，路径改为 `short-term/YYYY-MM-DD.json`
- 日期校验：`^\d{4}-\d{2}-\d{2}$`，防路径遍历
- 文件结构：`{ "date": "YYYY-MM-DD", "items": [...] }`
- item 格式扩展：新增 `type`, `category`, `session_id` 字段
- `add_item()` 参数新增 `date`, `type`, `category`, `session_id`
- `get_recent()` 保持跨文件聚合，按 mtime 倒序扫描日期文件
- `get_by_date(date)` 新增方法
- `get_summary()` 输出格式：`- [Weekday YYYY-MM-DD HH:MM] [{type}] {content}`
- `remove_items()` 适配新文件结构
- `cleanup_old(keep_days=14)` 清理过期文件
- `_format_ts()` 使用 `.astimezone()` 转本地时区

**验收标准**:
- 单元测试覆盖所有方法
- get_recent() 跨多个日期文件正确聚合
- get_summary() 时间戳为本地时区

### Task 5: Side Session Summary

**文件**: `side/tasks/session_summary.py`（改造现有）, `cli/app.py`, `memory/provider.py`

实现内容：
- 改造 SessionSummaryTask：
  - 输入：当前 session 的完整对话历史
  - 输出：简洁的事件摘要（3-5 句话）
  - 写入：type=event, source=side_summary, date=session 开始日期
- 覆盖所有退出路径：
  - `/clear` → `clear_session()` 前触发

- 幂等性：检查该 session_id 是否已有 type=event 的 item

**验收标准**:
